## 🚀 Featured Projects

### 1. 🔍 Advanced RAG Implementation

**An Advanced Multi-PDF Retrieval-Augmented Generation System**

Built an advanced RAG pipeline from scratch, incorporating multiple retrieval, ranking and context optimization techniques to improve document retrieval and answer generation.

**Key Features:**

- Multi-PDF Document Ingestion and Processing.
- Parent-Child Chunking Architecture.
- FAISS-based Vector Search.
- BM25-based Sparse Retrieval.
- Hybrid Retrieval and Reciprocal Rank Fusion (RRF).
- Multi-Query Expansion.
- Hypothetical Document Embeddings (HyDE).
- Cross-Encoder Reranking.
- Parent Document Retrieval.
- Embedding Compression and Mini-Chunk Splitting.
- LLM-based Context Filtering.
- Document Summarization and Routing.

**Tech Stack:** Python, FAISS, BM25, Sentence Transformers, Cross-Encoder, Ollama, Llama 3.

🔗 [**View Repository**](https://github.com/maddycode5/RAG_implementation)
