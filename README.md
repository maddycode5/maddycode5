1. 🔍 Advanced RAG Implementation
An advanced multi-PDF Retrieval-Augmented Generation system designed to improve document retrieval and answer generation through multiple retrieval, ranking and context optimization techniques.

Highlights
- PDF ingestion and parent-child chunking.
- FAISS vector search and BM25 sparse retrieval.
- Hybrid retrieval with Reciprocal Rank Fusion (RRF).
- Multi-query expansion and Hypothetical Document Embeddings (HyDE).
- Cross-encoder reranking and parent document retrieval.
- Embedding compression, mini-chunk splitting and LLM-based filtering.
- Document summarization and routing.
Tech Stack: Python, FAISS, BM25, Sentence Transformers, Cross-Encoder, Ollama and Llama 3.
